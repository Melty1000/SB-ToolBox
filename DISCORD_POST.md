**SB ToolBox**

**SB ToolBox is live**
SB ToolBox is a utility for **Streamer.bot import/export workflows**.

If you've ever wanted to quickly inspect an import before running it, or rebuild an import after editing scripts, this is built for that.

**What it does**
- **Decoder mode:** Paste an import string (or load a file) and inspect what is inside before importing.
- **Encoder mode:** Take your edited export JSON + scripts and rebuild a Streamer.bot-ready import string.
- **Simple goal:** Make import review and rebuild steps faster and easier.

**Where to use it**
- **Web App:** <https://melty1000.github.io/SB-ToolBox/>
- **GitHub Repo:** <https://github.com/Melty1000/SB-ToolBox>

**Download options**
- **Web version** (runs in browser)
- **Windows installer/portable builds:** not published yet in GitHub Releases.

**Compatibility**
- Current Streamer.bot compatibility target: **1.0.4**
- It will most likely work with earlier Streamer.bot versions, but those versions have **not** been tested yet.
- Desktop support is currently **Windows**

**Important safety note**
SB ToolBox helps you **inspect and rebuild** imports.
It does **not** auto-judge whether a script is safe or malicious.
Always review code you don't trust before running it.
